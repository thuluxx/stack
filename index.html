Codebase Intelligence Engine

A read-only analysis system that turns a Python repository into explainable engineering insight by combining static analysis, dependency discovery, complexity metrics and Git-history mining.

Problem

  • No single, dependable view of a project’s structure and technical condition.
  • Existing tools cover one dimension: linting, coverage or version control.
  • Dense dependency chains make changes risky to propagate.

Objectives

  • Parse Python repositories into modules, classes, functions and imports.
  • Compute size, complexity, coupling and code-smell indicators.
  • Mine Git history and rank modules for developer attention.

Scope

  • Python repositories supplied as a local path.
  • Untrusted repository code is never executed.
  • CI integration, cloud hosting and auto-refactoring are future extensions.
